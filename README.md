# 🏰 Orlando 2026 — Os 15 anos da Nathalia

Site da viagem da Família Viana a Orlando para comemorar os **15 anos da Nathalia**.
**22 de novembro a 11 de dezembro de 2026** · 4 viajantes · 6 parques.

## 🌐 Páginas do site
| Página | Arquivo |
|---|---|
| Início (home + contagem regressiva) | `index.html` |
| Roteiro completo (dia a dia) | `plano-nathalia.html` |
| Guia hora a hora dos parques | `guia-parques.html` |
| O Dia da Nathalia (aniversário) | `dia-da-nathalia.html` |
| Reservas Disney | `cartao-reservas.html` |
| Custos, hospedagem e dicas | `roteiro-orlando.html` |
| Álbum da viagem | `album.html` |

## 📸 Fotos
- Fotos selecionadas ficam na pasta `img/` e são listadas em `fotos.js`.
- O álbum principal da viagem é no **Google Fotos** (botão na página `album.html`).

## 🚀 Como publicar (GitHub Pages)
1. Suba todos os arquivos para o repositório (mantendo a pasta `img/`).
2. **Settings → Pages → Branch: main → / (root) → Save**.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

> Mantenha os nomes dos arquivos como estão — os links dependem deles.
> O arquivo de entrada é o `index.html`.
